# 스위치 진단 코드

GPIO16/17/18/19를 원본 펌웨어의 정지 상태 LOW로 유지합니다.
GPIO27은 원본에서 확인한 입력이며 GPIO26/14는 단자 표시에서 나온 후보입니다.
INPUT_PULLUP으로 읽으며 좌우 대응이나 눌림 극성은 단정하지 않습니다.
GPIO23은 하드웨어 용도 미확인으로 건드리지 않습니다.
블루투스와 이동 기능은 없습니다.

## 사용

원본 백업: C:/Users/SEC/ESP32_Obstacle_Backup/
IDE에서 이 폴더의 .ino를 열고 ESP32 Dev Module과 실제 USB 포트를 선택합니다.
기존 펌웨어를 실행하지 않는 BOOT 다운로드 모드에서 업로드합니다.
업로드는 기존 실행 펌웨어를 대체합니다. 장치는 진단 동안 앱에 연결되지 않습니다.
시리얼 모니터 115200 baud에서 다음 상태를 각 1초 이상 관찰합니다.

1. 아무것도 누르지 않음
2. 왼쪽 스위치만 누름
3. 놓음
4. 오른쪽 스위치만 누름
5. 놓음

출력: GPIO27=HIGH | GPIO26=HIGH | GPIO14=HIGH (예시)
입력 변화에 30ms 디바운스를 적용하고 1초마다 전체 상태도 출력합니다.
각 상태의 출력을 비교해 GPIO와 스위치 대응을 확인합니다.
변화가 없으면 후보 핀, 스위치, 배선, 입력 회로를 다시 확인해야 합니다.

리셋 중 모터 드라이버 상태는 보장하지 못합니다.
움직임이나 갈리는 소리가 생기면 즉시 장치 전원을 끄세요.
펌웨어 업로드 및 실물 검증은 수행하지 않았습니다.
